## 🚀 开始前需要准备什么？

在动手之前，你需要：

- ✔ 一台 **有公网 IP 的服务器（VPS）**
- ✔ 会一点点基础命令行操作（能连 SSH 就行）
- ✔ 已经装好《星露谷物语》

> 不用太担心，我会尽量把关键步骤写清楚，新手也能慢慢跟下来。
